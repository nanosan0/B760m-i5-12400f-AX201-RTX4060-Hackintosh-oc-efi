# v1.1.0 — Wi-Fi 切到 Tahoe 原生栈，声卡恢复原版 AppleHDA

发布日期：2026-11-02

## 主要变化

### Wi-Fi：不再使用 OCLP-Mod 根补丁

| 项目 | v1.0.1 | v1.1.0 |
| --- | --- | --- |
| 驱动 | `AirportItlwm` 2.3.0（Ventura 构建） | `AirportItlwm` 2.4.0（Tahoe 构建 `7204c69`） |
| 协议栈 | `IOSkywalkFamily.kext` + `IO80211FamilyLegacy.kext` + `AirPortBrcmNIC.kext` | 系统原生 `IO80211Family` 1200.13.1 |
| `Kernel > Block` | 3 条 | 2 条（删除 `IOSkywalkFamily`） |
| 根补丁 | 需要 OCLP-Mod | 不需要 |
| 结果 | `en1` 在，但 Wi-Fi 开关打不开 | 5 GHz / 802.11ac / WPA2 正常连接 |

### 声卡：新增 SimpleHDA

macOS 26 移除了 `/System/Library/Extensions/AppleHDA.kext`，音频设备列表为空。
新增 `SimpleHDA.kext` 1.0.0（Lilu 插件，OpenCore 注入恢复原版 AppleHDA，不写系统卷），
加载顺序 `Lilu → AppleALC → SimpleHDA`，沿用 `layout-id = 77`。

### 其他

- 新增 `SMCNvidiaGPU.kext`
- 清理未引用的 `WhateverGreen` / `UTBDefault`，`Kexts/` 精简为 20 个、全部启用
- OpenCore 版本标注更正为 **1.0.9**（NVRAM `REL-109-2026-09-30`）
- `config.plist` 通过官方 `ocvalidate` 校验：`No issues found`

## 升级注意

1. 三码是占位符，先用 GenSMBIOS 生成自己的 `MacPro7,1` 三码。
2. 从 v1.0.1 升级：直接用本包覆盖 `EFI`，但**保留你自己的 `PlatformInfo > Generic`**。
3. 若之前用 OCLP-Mod 打过根补丁，请先在 OCLP 里 Revert Root Patches，否则残留会干扰。
4. 回滚：换回旧 EFI 即可；本版本不改系统卷、不动 NVRAM。
